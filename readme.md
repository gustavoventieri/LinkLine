# 💬 Link Line

**Link Line** é um sistema de chat **seguro**, **moderno** e **inovador**, construído do zero com foco em **comunicação eficiente**, **escalabilidade**, e **experiência do usuário**. A proposta central é oferecer uma plataforma completa de mensagens em tempo real, pensada para **ambientes profissionais, educacionais ou sociais**, onde a confiabilidade na troca de informações é essencial.

O projeto nasce da necessidade crescente por soluções de **mensageria personalizáveis**, de **código aberto**, que não dependam de grandes provedores e possam ser integradas a diversos tipos de aplicações. Com uma **arquitetura modularizada** e uso de tecnologias modernas como **Node.js**, **React**, **Docker** e **Prisma**, o Link Line garante **flexibilidade no desenvolvimento**, **segurança no armazenamento de dados** e **baixa latência na comunicação**.

Ideal para startups, equipes de desenvolvimento, plataformas educacionais, ou qualquer sistema que necessite de **comunicação integrada e segura**, o Link Line é uma base sólida para escalar soluções de chat com qualidade de produção.


## 🌟 Principais Funcionalidades

- 🔒 **Criptografia e segurança** para proteger mensagens e usuários
- 💬 **Mensagens em tempo real** com excelente performance
- 🧩 **Arquitetura modularizada** que favorece escalabilidade e manutenção
- ⚙️ **Ambiente Docker-ready**, ideal para desenvolvimento e produção
- 🧪 **Testes automatizados** com alta cobertura usando Jest
- 📄 **API com documentação interativa** via Swagger
- 💻 **Interface moderna**, responsiva e construída com Material UI
- 🧠 **Clean Code** e boas práticas de engenharia de software


## 📌 Motivação do Projeto

A maioria das soluções de chat disponíveis atualmente são fechadas, pouco customizáveis ou voltadas para um público muito específico. O **Link Line** surge como uma resposta à necessidade de:

- 🔧 Ter um **chat personalizável**, com código aberto e arquitetura limpa;
- 📡 Integrar comunicação em tempo real a plataformas web já existentes;
- 🛡️ Garantir **segurança na troca de mensagens**, com autenticação e controle de acesso;
- 📱 Entregar uma **experiência de usuário moderna**, intuitiva e acessível em todos os dispositivos;
- 🚀 Suportar crescimento com uma **infraestrutura escalável** e pronta para produção com Docker.



## 🎯 Casos de Uso

## 🛠️ Como Começar

### 1. Clone o repositório

```bash
git clone https://github.com/gustavoventieri/LinkLine.git
cd LinkLine
````

### 2. Suba os containers com Docker

```bash
docker-compose up --build
```

> Isso irá iniciar tanto o back-end quanto o front-end e o banco de dados PostgreSQL.

### 3. Acesse o projeto

* Front-end: `http://localhost:5173`
* Back-end (Swagger): `http://localhost:3000/swagger/api-docs`
